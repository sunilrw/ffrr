FFRR Complete CLI, fnr.exe, Macro, Archive & Cloud Reference Manual

Every switch below works identically across macOS, Linux, and Windows (`ffrr` / `ffrr.exe`).

1. Core Find, Replace & Source Switches
-f, --find <PAT>         Pattern to find (or 1st positional arg)
-r, --replace <STR>      Replacement string (omit for Find-Only)
-d, --dir <PATH_OR_URI>  Folder, archive, @profile, or remote URI
-m, --file-mask <MASK>   Include masks ("*.rs,*.cs,*.json")
-x, --exclude-mask <M>   Exclude masks ("*.dll,*.exe,*.min.js")
    --exclude-dir <D>    Skip folders (".git,node_modules,target")
    --no-recursive       Do not scan subdirectories
    --no-archives        Skip .zip/.rar/.tar.gz/.gz/.zst archives
    --hidden             Include hidden dot-files
    --no-gitignore       Ignore .gitignore rules
    --min-size / --max-size <BYTES>
2. Matching, Case, Scope & Output Switches
-E, --regex              Regular expression mode ($1, ${name})
-F, --fixed-strings      Literal fixed-string mode
-s, --case-sensitive     Case-sensitive matching
-i, --ignore-case        Case-insensitive (default: Smart Case)
-w, --word-regexp        Whole word only
-P, --preserve-case      Smart case-preserving replace
-U, --multiline          Multiline dot matching
    --escape             Parse \n, \r, \t, \xHH escapes
-v, --invert-match       Non-matching lines only
    --filename-only      Instant filename/path-only search
    --content-only       Search inside file contents only
    --scope <SCOPE>      all | code | comments | strings | keys | values
-n, --dry-run            Preview without modifying disk
    --diff               Print unified diff
-B / -A / -C <N>         Context lines before / after / both
-c / -l                  Count only (-c) or filenames only (-l)
-o, --output <FMT>       table | compact | diff | json | csv | files
-j, --threads <N>        Parallel worker threads (default: 4)
3. 100% Drop-In Classic fnr.exe Switches
ffrr --cl --dir "samples" --fileMask "*.json,*.rs" \
  --excludeFileMask "*.dll" --includeSubDirectories \
  --caseSensitive --useRegEx --useEscapeChars \
  --find "http://(\S+)" --replace "https://$1" \
  --encoding "utf-8" --KeepModifiedDate --logFile out.log

5. Remote / Cloud URIs & Saved @Profiles

smb://server/share/folder          \\server\share\folder

Save Profile: ffrr connections --add prod-ssh="ssh://ubuntu@host:/var/log"
Use Profile : ffrr -f "ERROR" -d "@prod-ssh"

ffrr dupes -d samples --normalized --near --similarity 0.80
ffrr intent -d samples --pack secrets|pii|insecure-http|todos
ffrr undo [--list]
